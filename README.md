# MOODYSSEUS: I Have Read This Book — Character Variant B

**Play now / 立即遊玩:** https://gamegen-diy.github.io/odysseus-cinema-b/

Same interactive-cinema epic as the main build, with an alternate hero character replacing Odysseus throughout — a technical/creative test of swapping the protagonist while keeping the story, engine, and voice work identical. English voice-over, subtitles in **English / 繁體中文** (switch in the ☰ menu), choice cards with tone tags, and a persuasion-meter boss fight against the Cyclops.

同一套互動電影史詩,主角全程換成另一個角色(牛德賽)——測試「換主角、故事引擎配音全不變」這個玩法。字幕可切英文/繁體中文(右上 ☰ 選單)。

## How to play / 怎麼玩
- Tap to advance the story; pick a card to choose. / 點畫面推進劇情,點卡片做選擇。
- Boss scene: read the 👁 intel, cross the gold line to survive. / BOSS 戰:讀 👁 情報,把說服條推過金線才能活。
- ☰ menu: voice / music / autoplay / language / restart. / 選單:語音/音樂/自動播放/語言/重來。
